START HERE
Open index.html for the visual asset guide. The kit contains transparent PNG logos, favicon sizes, a glowing square PFP, a 3:1 X banner, a 35-second hero-video script and editable SVG logo sources.

IDENTITY
The mark is the moodboard's nested peaked-arch motif, reconstructed as precise native geometry. The separate custom wordmark uses thin-to-medium geometric uppercase lettering with generous tracking. These are clean reconstructions from a raster reference, not extracted original vector files. All logo shapes and lettering in the SVG files are paths and need no installed font.

TYPE & SPACING
Use Space Grotesk for headings and Inter for body/interface copy, as labeled on the moodboard. Font files are not bundled. The custom outlined wordmark is supplied separately and does not rely on either font. Do not retype it for the primary lockup.
Keep at least one outer-pier width of clearspace around the mark. For a website navigation bar, use the horizontal lockup at roughly 200–260 CSS pixels wide. Use the standalone mark below that size. Favicons are a deliberately compact exception to clearspace guidance.

PRODUCTION
The flat mark and custom wordmark were authored as precise path geometry and exported to transparent PNGs. The two social visuals were made with the built-in image_gen tool using the supplied moodboard and final logo as references. The prompt set is in source/generation-prompts.json. Source SVGs are included for clean future exports.
